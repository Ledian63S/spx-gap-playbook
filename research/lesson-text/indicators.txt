 A few useful answers
 Frequently asked questions
 Are LumiTraders TradingView indicators free? 
 Yes. These are free, protected-source scripts on TradingView. You need a TradingView account to add them to a chart. TradingView's own plan limits, market-data access and drawing limits still apply.
 Which indicator should I use? 
 Use Key Levels to map session ranges, opens and reference levels. Use ICT HTF Candles + CISD for higher-timeframe candles, sweep and reclaim levels, SMT and ICT projections. Use RTH Gap Fibs to map Fibonacci levels across regular-session gaps and track their unfilled portions.
 How do I add an indicator to TradingView? 
 Sign in to TradingView, open the indicator's script page and select Add to favorites. Then open a compatible chart and choose the script under Indicators › Favorites. Each guide lists the exact TradingView name and any timeframe requirements.
 Can I use all three indicators together? 
 The scripts draw different reference points, so you can combine them on a compatible chart if your TradingView plan has enough indicator slots. Check each script's timeframe requirements and reduce the enabled drawings if the chart becomes crowded.
 Do these indicators generate buy or sell signals? 
 No. They draw reference levels and chart structure. Key Levels maps sessions and anchors, ICT HTF Candles + CISD shows sweeps and reclaim levels, and RTH Gap Fibs tracks session gaps. These drawings do not place orders or promise trading outcomes.
 Where can I find the source and release notes? 
 Each guide links to the original LumiTraders script publication on TradingView and includes its documented release history. The scripts are protected source, so their Pine code is hidden. Open-source foundations are credited on the relevant indicator pages.
